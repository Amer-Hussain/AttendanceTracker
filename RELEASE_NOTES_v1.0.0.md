# Attendance Tracker v1.0.0

Initial public distribution release.

## Included

- Attendance percentage calculator and target selection.
- Total, present, and absent class controls.
- Upcoming attendance trajectory guidance.
- Calendar marking for Present, Absent, and Holiday.
- Notes and device-local persistence between normal app launches.
- Custom Attendance Tracker launcher icon and app header.

## Before publishing

Publish these notes only after building and testing the signed release APK on a physical Android device. Verify that changing attendance data, closing the app, and reopening it preserves the saved records.
