# Privacy Summary — Attendance Tracker

_Last reviewed: 18 October 2026_

Attendance Tracker is designed to help a user record class attendance on their own Android device.

## Data stored by the app

The app stores attendance-related information such as class counts, target percentage, date range, marked Present/Absent/Holiday dates, and notes in app-local storage so it can be restored between normal app launches.

## Accounts, cloud sync, and sharing

This release does not provide user accounts or a cloud-sync feature. Attendance records are intended to remain in the app's local storage on the device. The app's publisher does not receive those records through a built-in attendance sync service in this release.

## Retention and deletion

Local records may be removed if the user clears the app's storage/data or uninstalls the app. This release does not provide a server-side recovery option for such records.

## Third-party services

This summary describes the intended behavior of this release. If a distribution build adds analytics, advertising, crash reporting, remote services, or other third-party SDKs, this document and any required disclosures must be updated to match the actual build.

## Contact

For questions about this release, please use the GitHub Issues page for this repository. Do not include personal attendance records, medical details, student IDs, or other sensitive information in public issues.
