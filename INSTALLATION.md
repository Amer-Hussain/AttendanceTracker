# Installing Attendance Tracker on Android

## Download the APK

1. Open the repository's **Releases** page.
2. Select the latest stable release.
3. Under **Assets**, download `AttendanceTracker.apk`. Do not download the repository source-code ZIP if your goal is only to install the app.

## Install it

1. Open the downloaded APK from your browser's Downloads list or your file manager.
2. If Android requests permission, open the system settings page and allow that specific browser or file manager to install unknown apps.
3. Return to the installer, review the app name, and tap **Install**.
4. Open Attendance Tracker after installation.

The exact labels may differ across Android versions and phone manufacturers. Do not disable security protections globally. Only install the APK if you trust its source.

## If Android refuses to install it

- Confirm the download completed and the file ends in `.apk`.
- Download the latest release again if the file may be incomplete.
- Make sure the app supports your Android version and device architecture.
- If an older version is installed, a version signed with a different key may not install as an update. Do not uninstall an existing app if you need to preserve its locally stored data unless you understand the data-loss risk.

## Keeping attendance data

The app is designed to retain its locally saved attendance data when the app is normally closed and reopened. Clearing app storage/data or uninstalling the app can erase that information. This release does not provide cloud sync or cross-device backup, so keep any separate records you consider important.
